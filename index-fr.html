05 — Standards

Discipline
Ingénierie.

La qualité du code n'est pas un bonus — c'est la norme. Chaque projet est livré avec CI, une archi clean et sa documentation.

01
Discipline dans le contrôle de version

Commits sémantiques, stratégie feature branch, revue des PR. Chaque dépôt raconte l'évolution du produit.

02
CI/CD via GitHub Actions

Test auto → compilation → déploiement à chaque push. Pas de publis manuelles. Pas de "ça marche chez moi".

03
MVVM & Clean Architecture

Couches présentation, domaine et data conservées strictement séparées. ViewModels ignorants les vues. Repositories ignorants l'UI.

04
La documentation comme Livrable

READMEs, documentation API, commentaires inline, et diagrammes d'archi. Tout projet est compréhensible.
